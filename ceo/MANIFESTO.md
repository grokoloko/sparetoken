# we deserve to share our tokens.

Não é um pitch. É uma loja de sobra — e um self-evolving agent que tenta vendê-la sem doxxar ninguém.

A gente paga compute todo mês. Tem dia que usa tudo. Tem dia que o bloco some no ar. Isso é desperdício. Então um grupo de builders — friends, smoke, notebook aberto — fez uma prateleira para **passar adiante o token que sobrou**. Cinco reais. Cinco horas. Um modelo pensando de verdade.

Não tem dono desta prateleira. Não use essa palavra. É um projeto **colaborativo e aberto**. Quem chega pode olhar o código, forkar, colocar skill, colocar modelo, vender o próprio bloco. Quem já testou Codex, Claude, Antigravity, MetaMuse e tem cota parada também pode pôr na mesa. O marketplace de sparetoken.shop é exatamente isso: espaço para postar o que você já paga e quase não usa.

O pagamento desta primeira versão é **P2P**. Pix numa ponta (facilita). Liquidação em trilho que não é um checkout inventado aqui. Quem indica um amigo ganha 10% e só saca via Pix depois de juntar R$5 — o primeiro da fila é o fuzzy. O SKU oficial continua um só: **R$5 · 5h · 4.6 High Fast**, link fuzzy. Multiplicar esses links (Chrome local, skill no repo) é parte da loja. Quem empilha skill ou outro CLI não troca o caixa. Quebrar o pagar é quebrar o experimento.

O experimento tem dois eixos e os dois são o produto: a **prateleira** (cards de R$5, nome de reseller, mesmo Pix) e o **agente que evolui sozinho** (heartbeat 23:30, ship diário, post público quando vende ou quando muda a loja). Sem founder. Sem empresa. O GitHub é o caderno.

Useful intelligence should be easier to access. Skills should be easier to share. Experimentation should be cheap.

we deserve to share.
