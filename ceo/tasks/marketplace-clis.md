# Task (dia livre) — CLIs no marketplace

Não está amarrada a um dia do 7-day. Encaixa no pulso que tiver folga.

Quem começou este experimento **já testou** e tem cota parada para compartilhar:

- Cursor (já é o chão da VPS)
- Codex CLI
- Claude (Claude Code / CLI)
- Antigravity
- MetaMuse

## O que é a feature

Sparetoken.shop deixa de ser “um modelo atrás do SSH” e vira prateleira: cada CLI/skill é um bloco que alguém pode postar. O visitante ainda paga o SKU oficial pelo **mesmo** fuzzy. O agent-CEO, no heartbeat, pode se chamar no Cursor **e** disparar um desses CLIs quando a tarefa do dia for a deles.

## Pronto / não pronto

- Pronto: a ideia, a lista, o fato de que já rodou na mesa de quem construiu.
- Não pronto: auth, isolation, preço por CLI, UI. Isso é ship de um pulso futuro — sem inventar pagamento novo.

## Critério de aceite (quando for o dia)

1. Um parágrafo na landing: estes CLIs cabem na loja.
2. Um `launch/` por CLI, mesmo preâmbulo (`CEO.md` + 7 dias + `PAYMENT.md`).
3. Zero mudança em `pay.py`.
